# Research digest — Recent mobile smash hits (2016–2026, bias 2021+)

Compiled 2026-07-31 for the PULL improvement report. Method: ~20 targeted searches; synthesized from search-result content of the primary sources listed (direct page fetches were partially blocked in the research sandbox).

## Case studies (compressed)

- **Suika Game (Aladdin X, 2021 → explosion late 2023).** Drop fruit, identical fruits merge, survive the rising pile. Zero tutorial — the first merge teaches the whole game in seconds. Soft-body wobble = continuous visible near-miss tension; the overflow line makes death creep legibly. Streamer-readable board state drove virality (~1,200 units Sept 2023 → 400k in 7 days that October; most-downloaded Japan eShop game of 2023). *Lesson: physics wobble is a feature; make the failure state creep visibly.*
- **Vampire Survivors (poncle, 2022; mobile Dec 2022).** Move-only input; instant combat; first level-up under a minute. Trivial input → massive output. Failed runs engineered to land near the next visible unlock. 1M mobile downloads in a week with zero UA. *Lesson: one-verb input must buy escalating spectacle; every death should land near a visible threshold.*
- **Balatro (LocalThunk, 2024; mobile Sept 2024).** Familiar object (cards) makes round one legible; the scoring animation itself is the hook — digits roll like slot reels, chips-then-mult resolve sequentially, pitch-synced sounds, flames on big multipliers. "Presentation can turn a number into a moment." 5M copies in under a year. *Lesson: dramatize scoring as staged theater.*
- **Wordle (2021–22).** One shared daily puzzle; the grid is the tutorial; no install — a URL. Scarcity builds anticipation and prevents burnout; streaks formalize the ritual; the spoiler-free emoji share grid was the viral vector (90 players Nov 1, 2021 → 2M Jan 9; ~10–12M DAU in 2025). *Lesson: for a web game, the share artifact is the install channel.*
- **Royal Match (Dream Games, 2021 → top grosser).** Nothing novel — faster, bigger, cleaner; polish-as-generosity (free shuffle, potent boosters, breather levels): a game "on the player's side." Beat Candy Crush in downloads and revenue July 2023; 51% of Western match-3 IAP revenue 2024. *Lesson: execution beats novelty; audit every frustration for a player's-side alternative.*
- **Monopoly GO! (Scopely, 2023).** One tap (roll) with an emotional outcome each time; over a year iterating the dice roll alone; a "list 100 feelings" playtest exercise; appointment loop via regenerating dice; anticipation staging everywhere. $1B in 7 months. *Lesson (non-casino): stage anticipation before resolution; iterate the single core gesture obsessively.*
- **Block Blast (Hungry Studio, 2022 → #1 downloads 2024–25).** Drag-clear comprehension in one move; an A/B-testing obsession and dynamic difficulty predicting player behavior to stay "just hard enough." 368M downloads in 2025. *Lesson: tune the ramp empirically; adaptive difficulty is the highest-leverage retention system for this shape of game.*
- **Brawl Stars resurgence (2023–24) / Squad Busters (2024).** After removing loot boxes, players missed "the surprise effect of getting rewards"; Starr Drops (escalating-rarity capsule reveals) + clearer goals → revenue 8.8×, DAU 3.9×. Squad Busters: record launch, then collapse — combat "chaotic and hard to read," depth arriving too late; Supercell: "We were wrong." *Lesson: staged escalating reveals are worth multiples; unreadable chaos kills regardless of pedigree.*
- **Crossy Road (2014; Castle 2020) — the arcade template.** Sub-minute runs; death instant, comic; collection layer defined the genre: coins → Prize Machine (100 coins = random character), timed free gifts, secret in-world unlocks generating years of discovery content; ads only at high-score moments. $10M/90 days. *Lesson: bank a run currency into a collection; it converts "one great run" players into "one more unlock" players.*
- **Alto's Odyssey (2018) / Monument Valley 2 (2017).** Alto: 60 levels × 3 concurrent hand-crafted micro-goals over an endless run; characters at milestones; Zen Mode strips score entirely. 12 months of sketches to find tone; calm as differentiator. *Lesson: adopt the 3-goals scaffold so mediocre runs still progress something.*
- **Pokémon GO (2016).** Habit welded to an existing daily behavior, then formalized with streaks and Community Days. *Lesson: attach the game to an existing daily moment; reward the streak, not just the score.*
- **Archero (2019) / Survivor.io (2022).** One thumb; standing still auto-fires — movement and attack mutually exclusive: a single input carrying permanent risk/reward tension. *Lesson: the magic is a single input that embodies a trade-off — PULL has this natively; sharpen and telegraph it.*
- **Whiteout Survival / Last War (2023–25).** Trivially comprehensible minigames ARE the first minutes of the real game (>60% of the first 4–5 minutes), then recede. *Lesson: instant first-minute comprehension is the scarcest asset in mobile; PULL's core is ad-legible in 3 seconds — build every screenshot and clip around one readable image.*
- **Hyper-casual wave (2017–20) → hybrid-casual (2022+).** Helix Jump etc. proved instant comprehension + satisfying physics reach billions (D1 ~40%, sub-minute time-to-fun); the model collapsed post-ATT because zero-depth retention evaporated. "Hyper-casual got you to play once; hybrid tries to get you to play tomorrow." *Lesson: hyper-casual's bar for the first 60 seconds is the right bar; its graveyard is what happens if days 2–14 have nothing to unwrap.*

## Cross-cutting patterns

1. One trivial verb, disproportionate consequence — depth lives in consequences, not controls.
2. The first minute is the whole game, legible without words.
3. A single input that embodies a trade-off outlasts one that doesn't.
4. Score is theater (Balatro).
5. Staged anticipation beats instant payout (Starr Drops; Monopoly GO).
6. Failure must be cheap, fast, funny, and near-miss shaped.
7. Charm objects carry sharing and collection.
8. Collection/goal scaffolding is how score-chasers retain — raw high score alone retains no one.
9. Generosity reads as premium polish.
10. Readability is existential (Squad Busters died of it).
11. Daily ritual and scarcity build habit without content treadmills.
12. Feel is iterated obsessively, then A/B tuned.

## Retention benchmarks

- All-genre averages 2024–25: D1 ~27%, D7 ~8%, D30 <3%; "healthy" targets D1 30–40%, D7 10–20%, D30 5–10% (Segwise; AppAgent; MAF).
- Puzzle: D1 31.85% / D7 12.18% / D30 5.35% — best-retaining casual cluster.
- Arcade: best-in-class D1 of all genres, near-bottom long-term tail (GameAnalytics via GameDevReports).
- Hyper-casual bar: top titles D1 38–40%, D7 ~13%.
- Top-quartile session ~8–9 min (median 5–6), ~4 sessions/day, median daily playtime 22 min.
